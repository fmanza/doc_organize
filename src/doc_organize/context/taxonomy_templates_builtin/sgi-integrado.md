# Plantilla de taxonomía — SGI Integrado

Catálogo de ejemplo para un Sistema de Gestión Integrada que combina varios
referenciales (ISO 27001, ISO 22301, ISO 20000, ISO 9001, ENS...) en 7 dominios
de trabajo transversales, en vez de un único eje de cumplimiento normativo. Mismo
criterio que `calidad`/`sgi-iso27001`: úsala tal cual o copia su contenido a un
`taxonomy_manifest.md` de proyecto para adaptarla sin tocar la compartida.

| Eje | Ejemplos |
|---|---|
| Dominio | Gobernanza, Riesgos, Incidencia, Continuidad, Cadena de Suministro, Tecnología, Compromiso y Mejora Continua |
| Tipo de material | Normativa Legal, Política, Manual, Procedimiento, Plan y Estrategia, Declaración, Registro y Evidencia, Informe de Auditoría, Certificado |
